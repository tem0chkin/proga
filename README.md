# 🚗 Фиксация проезда автомобилей (Лабораторная работа №4)

## Тема

Добавление поддержки **файлов с командами** (`ADD`, `REM`, `SAVE`). Команды применяются к данным, загруженным через графический интерфейс.

---

## 📋 Задание

1. Добавить возможность открытия файла с командами
2. Реализовать команды:
   - `ADD <данные>` — добавление объекта в формате CSV
   - `REM <условие>` — удаление объектов, соответствующих условию
   - `SAVE <filename>` — сохранение текущего состояния в файл
3. Команды применяются к данным, изменённым через GUI
4. После выполнения команд таблица обновляется
5. Покрыть новый функционал модульными тестами

## 🎯 Новый функционал (Лаба 4)

### Команды

| Команда | Формат | Пример  | Описание |
|---------|--------|---------|----------|
| `ADD`   | `ADD дата,номер` | `ADD 2025.05.15,Т999УХ777` | Добавляет новую запись    |
| `REM`   | `REM условие`    | `REM date == "2025.05.11"` | Удаляет записи по условию |
| `SAVE`  | `SAVE путь`      | `SAVE result.txt`          | Сохраняет данные в файл   |

### Условия для REM

| Оператор | Пример | Что делает |
|----------|--------|------------|
| `==` | `date == "2025.05.11"` | Равно |
| `!=` | `plate != "А123ВС77"` | Не равно |
| `contains` | `plate contains "ВС"` | Содержит подстроку |
| `<` | `date < "2025.05.12"` | Меньше |
| `>` | `date > "2025.05.12"` | Больше |

### Пример файла `commands.txt`

```text
# Это комментарий
# Добавление новых записей
ADD 2025.05.15,Т999УХ777
ADD 2025.05.16,Х001ХХ99

# Удаление записей по условию
REM date < "2025.05.12"
REM plate contains "ВС"

# Сохранение результата
SAVE result.txt
