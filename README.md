## Общее описание

Программа для фиксации проезда автомобилей с проверкой корректности номеров (российский стандарт) и дат.

**Формат номера автомобиля:**
- Буква + 3 цифры + 2 буквы + 2-3 цифры региона
- Допустимые буквы: А, В, Е, К, М, Н, О, Р, С, Т, У, Х

**Формат даты:** `ГГГГ.ММ.ДД`
