# 🚗 Фиксация проезда автомобилей (Лабораторная работа №3)

## Тема

Разделение программы на **Модель**, **Представление** и **Контроллер** (MVP паттерн). Добавление **логирования ошибок** и **модульных тестов**.

---

## 📋 Задание

1. Выделить вспомогательные классы (Модель)
2. Разделить программу на Модель и Представление
3. Добавить обработку исключительных ситуаций с логированием в файл
4. Написать модульные тесты для Модели
5. Некорректные строки пропускать, но писать в лог

---

## 🎯 Функциональность

- **Главное меню** с кнопками: «Работать», «Справка», «Выход»
- **Рабочее окно** с таблицей всех фиксаций проезда
- **Добавление** новых записей с проверкой форматов
- **Удаление** выбранных записей
- **Сохранение** и **загрузка** данных из файла `.txt`
- **Логирование** всех ошибок в файл `error.log`
- **Модульные тесты** для модели (15+ тестов)
