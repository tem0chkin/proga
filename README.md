# Фиксация проезда автомобилей (Консольная версия)

Консольное приложение для учета проезда автомобилей. Программа позволяет добавлять, просматривать и искать записи о проезде автомобилей с проверкой корректности вводимых данных.

## 🎯 Функциональность

- **Добавление** новых фиксаций проезда с проверкой:
  - Корректность даты (ГГГГ.ММ.ДД)
  - Формат номера автомобиля (российский стандарт)
- **Просмотр** всех сохранённых записей в виде таблицы
- **Поиск** по номеру автомобиля
- **Поиск** по дате проезда
- Интуитивно понятное **консольное меню**
- Автоматическое переключение кодировки для Windows (CP1251)

## 💻 Требования

- Python 3.6 или выше
- Стандартные библиотеки: `os`, `re` (входят в состав Python)
- Никаких дополнительных зависимостей не требуется
