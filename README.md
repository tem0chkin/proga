1 ЛАБОРАТОРНАЯ. В рамках работы студенту необходимо разработать программу, формирующую программный объект на основе его описания в виде текстовой строки. В строке задается тип объекта и его свойства. Свойства могут иметь различные типы данных (целый, дробный, строковый, дата, время). Строкие свойства достигаются кавычками. Дата записи в формате гггг.мм.дд и записывается без кавычек. Время записи в формате чч:мм. Друг от другого свойства разделяются на один или более пробелов. Разработанная программа должна корректно обрабатывать различные варианты корректных входных данных (обработку ошибок невозможно выполнить). Типовые варианты заданий приведены в таблице: 8 вариант. Фиксация проезда автомобилей: дата, номер автомобиля (строка в характерном формате).
