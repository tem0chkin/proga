# 🚗 Фиксация проезда автомобилей (GUI версия)

Графическое приложение для учета проезда автомобилей с удобным интерфейсом на `tkinter`. Позволяет добавлять, удалять, сохранять и загружать записи о проезде автомобилей с проверкой корректности номеров.

## 🎯 Функциональность

- **Главное меню** с тремя кнопками: «Работать», «Справка», «Выход»
- **Рабочее окно** с таблицей всех фиксаций проезда
- **Добавление** новых записей с проверкой форматов
- **Удаление** выбранных записей (одной или нескольких)
- **Сохранение** данных в текстовый файл (`.txt`)
- **Загрузка** данных из текстового файла
- **Окно справки** с информацией о программе
- **Валидация** номера автомобиля по российскому формату
- **Валидация** даты в формате ГГГГ.ММ.ДД

## 💻 Требования

- Python 3.7 или выше
- Стандартные библиотеки (входят в Python):
  - `tkinter` — для графического интерфейса
  - `re` — для проверки номеров
  - `os` — для работы с файлами
- `Pillow` (опционально) — для отображения изображений в справке
